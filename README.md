# escuela-calidad-2026

Aplicación funcional para gestionar la Escuela de Calidad 2026, con:

- Dashboard de estudiantes
- Registro de asistencia
- Notas / observaciones
- Panel de métricas básicas
- Persistencia local en JSON para un uso inmediato sin base de datos

## Tecnologías

- Next.js 14
- React
- TypeScript
- API routes internas

## Instalación

```bash
npm install
npm run dev
```

Luego abre:

```text
http://localhost:3000
```

## Funcionalidades

- Agregar estudiantes
- Registrar asistencia (Presente / Tarde / Ausente)
- Guardar notas por estudiante
- Ver resumen general del programa

## Nota

La persistencia es local, ideal para empezar el proyecto sin configurar una base de datos externa.
